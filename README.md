# Yo Maquillo · maqueta (propuesta)

Propuesta de web para Yo Maquillo (Marta de la Coba, Córdoba). No indexable: noindex en todas las páginas y robots.txt bloqueando buscadores.

- `/`: v3 (portada) + 8 páginas de búsqueda
- `/v2/` y `/v1/`: vueltas anteriores
- Generador: `python -I fuente/v2/generar.py`
- Las fotos de `img/trabajos/` son de la propia web de la clienta (yomaquillo.com).
